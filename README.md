# 🍋 Lemon Clicker

Simple clicker game created as a college project

## 🚀 Technologies
* **React.js** (Functional components & Hooks)
* **CSS3** (Custom styling)
* **Local Storage API** (To save your progress)

## 🎮 Features
* **Lemon upgrades:** Buy items to increase your CPS (Clicks Per Second).
* **Save system:** Your balance and items stay with you even after refreshing the page.
* **Responsive Design:** Play on different screen sizes.

## 🛠️ How to run locally
1. Clone the repository:
   ```bash
   git clone https://github.com/sukarapu/Lemon-clicker.git
2. Install dependencies:
   ```bash
   npm install
4. Start the app:
   ```bash
   npm run dev
